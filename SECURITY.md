# Security

Please report vulnerabilities privately, through GitHub's
"Report a vulnerability" button on the Security tab of this repository.
Do not open a public issue.

Include what you found, how to reproduce it and what an attacker could do with
it. You will get an answer as soon as the report has been read.

This software handles customer data and credentials for third-party services.
If you run it, keep your `.env` and configuration files out of version control,
rotate any key that may have been exposed, and keep your deployment up to date.
